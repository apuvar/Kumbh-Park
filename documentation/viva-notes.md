## Assignment 1 – HTML

## Assignment 2 – Semantic HTML
**Q: Why use semantic HTML?**  
A: Semantic tags give meaningful structure to the webpage and improve readability and accessibility.

**Q: Name semantic tags used here.**  
A: Header, nav, main, section, article and footer.

## Assignment 3 – CSS
**Q: What is CSS?**  
A: CSS is used to style and design a webpage.

**Q: Which CSS type is mainly used?**  
A: External CSS using `style.css`.

## Assignment 4 – Responsive Design
**Q: What is Flexbox?**  
A: Flexbox is used for one-dimensional alignment of elements.

**Q: What is CSS Grid?**  
A: Grid is used to create rows and columns.

**Q: What is a media query?**  
A: It changes CSS rules according to screen size.

## Assignment 5 – Positioning
**Q: Why is the map relative?**  
A: So the parking pins can be positioned inside it.

**Q: Why is the navbar sticky?**  
A: It stays visible while the user scrolls.

## Assignment 6 – JavaScript
**Q: What is JavaScript?**  
A: JavaScript adds behavior and interactivity to webpages.

**Q: Which array functions are used?**  
A: `forEach`, `map`, `filter` and `find`.

**Q: Give one example.**  
A: `filter()` is used to show only the parking zones matching the search.

## Assignment 7 – Form Validation
**Q: Why validate a form?**  
A: To prevent incomplete or invalid data from being submitted.

**Q: What is checked?**  
A: Name, 10-digit mobile number, vehicle number, vehicle type, zone, slot, date and duration.

## Assignment 8 – React
**Q: What is React?**  
A: React is a JavaScript library for building user interfaces.

**Q: What is JSX?**  
A: JSX lets us write HTML-like UI syntax inside JavaScript.

**Q: Why functional components?**  
A: They are simple and easy to reuse.

## Assignment 9 – Props, State and Hooks
**Q: What are props?**  
A: Props are values passed from one component to another.

**Q: What is state?**  
A: State stores data that can change while the component runs.

**Q: What is `useState()`?**  
A: It creates state in a functional React component.

**Q: What is `useEffect()`?**  
A: It runs side-effect logic such as loading data.

## Assignment 10 – Fetch and JSON
**Q: What is Fetch API?**  
A: Fetch is used to make HTTP requests from JavaScript.

**Q: What is JSON?**  
A: JSON is a text format commonly used to exchange structured data.

## Assignment 11 – DOM
**Q: What is DOM?**  
A: DOM is the Document Object Model, which represents webpage elements as objects.

**Q: Which DOM methods are demonstrated?**  
A: `getElementById`, `querySelector`, `createElement`, `textContent`, `classList` and `addEventListener`.

## Assignment 12 – PHP Session
**Q: What is PHP?**  
A: PHP is a server-side scripting language.

**Q: What is a session?**  
A: A session stores user information across multiple PHP pages.

**Q: What is `$_POST`?**  
A: It receives form data sent using the POST method.

## Assignment 13 – PHP + MySQL CRUD
**Q: What is MySQL?**  
A: MySQL is a relational database management system.

**Q: What is CRUD?**  
A: Create, Read, Update and Delete.

**Q: Which table is edited by the admin?**  
A: `parking_zones`.

## Assignment 14 – Node + Express
**Q: What is Node.js?**  
A: Node.js allows JavaScript to run outside the browser.

**Q: What is Express?**  
A: Express is a Node.js framework used to build web servers and routes.

**Q: What is routing?**  
A: Routing decides what response should be returned for a URL and HTTP method.

## Assignment 15 – REST API
**Q: What is a REST API?**  
A: It is an API that exposes resources through standard HTTP methods.

**Q: What are GET, POST, PUT and DELETE?**  
A: GET reads data, POST creates data, PUT updates data and DELETE removes data.

**Q: Why connect Node.js to MySQL?**  
A: To store and retrieve persistent parking, vehicle and booking data.

## Basic Terms
- **HTML:** Structure of webpage.
- **CSS:** Styling and layout.
- **JavaScript:** Interactivity.
- **DOM:** Programmatic representation of HTML.
- **React:** UI library.
- **JSX:** HTML-like syntax in React.
- **Props:** Data passed to components.
- **State:** Changeable component data.
- **Hooks:** Functions such as `useState` and `useEffect`.
- **Fetch API:** Makes HTTP requests.
- **JSON:** Data exchange format.
- **PHP:** Server-side scripting language.
- **Session:** Stores server-side user state.
- **MySQL:** Relational database.
- **CRUD:** Create, Read, Update, Delete.
- **Node.js:** JavaScript runtime.
- **Express:** Node web framework.
- **REST API:** Resource-based web API.
- **GET:** Read.
- **POST:** Create.
- **PUT:** Update.
- **DELETE:** Remove.
