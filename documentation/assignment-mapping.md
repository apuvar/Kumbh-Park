# KumbhPark – Assignment Mapping

| Assignment | Implemented Feature | Where | What to Demonstrate | Viva Explanation |
|---|---|---|---|---|
| 1 | Basic HTML webpage | `index.html` Parking Facilities section and `images/kumbh-parking.svg` | Show headings, paragraphs, links, buttons, list/image usage | HTML creates the structure of a webpage. |
| 2 | Semantic HTML | `index.html` | Point out `header`, `nav`, `main`, `section`, `article`, `footer` | Semantic tags give meaningful structure and improve readability. |
| 3 | CSS styling | `style.css` | Show external stylesheet, classes and small inline style on print button | CSS controls presentation, colors, spacing and layout. |
| 4 | Flexbox/Grid/media queries | `style.css` | Show navbar/button Flexbox, parking/slot/stat grids and responsive breakpoints | Flexbox aligns items, Grid creates layouts and media queries adapt the page to screen size. |
| 5 | CSS positions | `style.css` | Show sticky navbar, relative map, absolute map pins, fixed help button | Positioning controls where elements appear on the page. |
| 6 | JS events and arrays | `js/script.js` | Search, buttons, slot selection, `forEach`, `map`, `filter`, `find` | JavaScript makes the static page interactive. |
| 7 | JS form validation | `js/script.js`, reservation section | Submit incomplete form and then valid form | Validation checks user input before booking. |
| 8 | React SPA | `react-app/src` | Run React and show functional components and JSX | React builds UI using reusable components. |
| 9 | React props/state/hooks/events | `react-app/src/components`, `App.jsx` | Select zone and slot in React demo | Props pass data, state stores changing data, hooks manage component behavior. |
| 10 | Fetch + JSON | `js/script.js`, `server/server.js` | Start Node and refresh; parking cards are loaded from `/api/parking` | Fetch requests data from an API and JSON carries structured data. |
| 11 | DOM manipulation | `#live-board` in `index.html`, `js/script.js` | Click A01/A03 and watch text/class change | DOM manipulation changes webpage elements using JavaScript. |
| 12 | PHP form/session | `php/login.php`, `dashboard.php`, `logout.php` | Login, open dashboard, logout | Session stores login state between PHP pages. |
| 13 | PHP + MySQL CRUD | `php/zones.php`, `database/smart_parking.sql` | Add, edit and delete a parking zone | CRUD means Create, Read, Update and Delete database records. |
| 14 | Node + Express server/routing | `server/server.js` | Run server and open `/`, `/api/parking`, `/api/zones`, `/api/bookings` | Express simplifies creation of a Node web server and routes. |
| 15 | REST API + MySQL | `server/server.js`, `routes/` | Use GET/POST/PUT/DELETE endpoints | REST APIs expose resources using standard HTTP methods. |

## Demonstration Order
1. Open the home page.
2. Explain semantic HTML and CSS.
3. Resize browser to show responsiveness.
4. Search for a zone.
5. Click a parking card or map pin.
6. Select an available slot.
7. Submit an invalid reservation to show validation.
8. Submit a valid reservation to show confirmation.
9. Show Live Parking Board for DOM manipulation.
10. Start Node and show Fetch/API data.
11. Run the React demo for Assignments 8–9.
12. Open PHP login and dashboard.
13. Add/edit/delete a zone.
14. Show API endpoints in browser/Postman.
15. Explain the MySQL tables.
